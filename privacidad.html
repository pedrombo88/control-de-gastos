Política de privacidad

Budviva es una herramienta de gestión de finanzas personales en fase beta. Esta página describe cómo funciona actualmente, no una futura versión con cuentas o sincronización.

Resumen: los movimientos, objetivos, presupuestos y desgloses que registras se guardan en el almacenamiento local del navegador del dispositivo que utilizas. Budviva no dispone actualmente de cuentas de usuario ni de un servidor propio de datos financieros.

1. Qué información utilizas en Budviva

Puedes introducir fechas, conceptos, importes, categorías, presupuestos, reglas recurrentes, objetivos de ahorro y aportaciones. También puedes seleccionar fotografías de tickets, imágenes, archivos PDF, texto y CSV para extraer datos y revisar los movimientos sugeridos.

2. Dónde se guardan los datos

La información que confirmas se guarda en el almacenamiento local del navegador (localStorage). Se mantiene en ese dispositivo y perfil del navegador hasta que la eliminas o el navegador borra su almacenamiento. No se sincroniza entre dispositivos ni existe recuperación automática de datos.

La versión actual puede conservar fotografías, PDF, CSV y otros originales importados o adjuntados manualmente en el almacenamiento IndexedDB de este mismo dispositivo, asociados a movimientos que confirmes. El almacenamiento depende de las cuotas y del espacio disponible en Safari. Si falla, la app solicita una decisión expresa antes de guardar únicamente los movimientos.

3. Tratamiento de tickets y extractos

El reconocimiento OCR y la lectura de PDF se ejecutan en el navegador. Las bibliotecas Tesseract.js, los archivos del modelo de español y PDF.js se distribuyen desde el mismo origen de Budviva mediante GitHub Pages. Su descarga inicial y posterior actualización genera solicitudes al proveedor de alojamiento GitHub Pages, no a servicios CDN de terceros. No está implementada una función de envío deliberado de tus tickets o extractos a un servidor propio de Budviva.

La extracción de datos puede contener errores. La aplicación exige revisar las operaciones antes de guardarlas. No conectes tus credenciales bancarias: Budviva no solicita acceso a cuentas bancarias.

4. Copias de seguridad y exportaciones

Desde Ajustes puedes descargar una copia completa JSON con los registros y originales guardados, una copia opcional cifrada con contraseña mediante AES-256-GCM, y exportar los movimientos a CSV. Los JSON sin cifrar y CSV pueden incluir información financiera sensible. Las copias cifradas usan una contraseña que Budviva no recupera ni almacena: si la pierdes, perderás el acceso a esa copia. Guarda tus archivos y contraseñas de forma segura. Evita compartirlos sin necesidad.

5. Alojamiento y terceros

La web se publica mediante GitHub Pages. GitHub Pages puede tratar información técnica de conexión según su política de privacidad. En la versión revisada no se han identificado SDK de anuncios, analítica de comportamiento ni un servicio de sincronización financiera.

6. Conservación, control y eliminación

Puedes editar y borrar movimientos individuales, eliminar objetivos y aportaciones y usar Ajustes → Borrar datos financieros para eliminar tanto los datos financieros como los originales guardados por Budviva en este dispositivo. La eliminación no borra las copias JSON, archivos cifrados o CSV que hayas descargado, ni la información técnica que puedan conservar los proveedores externos. La preferencia visual del tema puede permanecer en el navegador.

También puedes borrar los datos de este sitio desde los ajustes de Safari. Recuerda exportar primero una copia si quieres conservar tus registros.

7. Seguridad y limitaciones

Se utiliza la conexión HTTPS de la plataforma de alojamiento y validación básica de los datos importados. El almacenamiento local del navegador no sustituye al almacenamiento cifrado protegido de una app bancaria ni protege frente a todos los riesgos de un dispositivo compartido o comprometido. No introduzcas contraseñas bancarias ni otros secretos.

8. Contacto y cambios

Para consultas técnicas y sobre el funcionamiento de la app, utiliza la página de soporte. Esta es una política informativa de la fase beta. Antes de la comercialización deberá completarse la identificación del responsable del tratamiento y validarse el texto jurídico conforme a la distribución y tratamiento reales de datos.
